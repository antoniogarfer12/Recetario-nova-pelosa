Sincronización

Las recetas se guardan en el archivo recetas.json del repositorio de GitHub, y cada cambio actualiza automáticamente recetas.xlsx. Para añadir o editar recetas desde este dispositivo necesitas un token de GitHub (se configura una sola vez y solo se guarda en este navegador).

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Ponle un nombre (p. ej. “Recetario”) y una caducidad.
  3. En Repository access elige “Only select repositories” → Recetario-nova-pelosa.
  4. En Permissions → Repository permissions, pon Contents en “Read and write”.
  5. Genera el token, cópialo y pégalo aquí.
